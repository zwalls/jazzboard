## Calibration and its limits

The declared callback-cost screen was 20 ms median / 50 ms p95 for a 267,642-byte
synthetic JSON result, with three warmups and ten measured calls, preserved
result identity, and complete collection. The initial fresh Node VM method
failed: approximately 169.941 ms median / 186.382 ms p95. Its aggregate-only
diagnostic is explicitly reconstructed; raw samples were not retained.

Before any author run, the method was amended to run the generated module in
Chromium 151. That synthetic browser calibration measured 13.900 ms median /
18.090 ms p95 / 18.900 ms maximum added callback time. It preserved identity
and sealed 13 invocations across 30 events with no rejections or gaps.
Controller acknowledgement after evaluation had a separate 227.917 ms median;
it is not included in callback time. Node/ESM measured 10.456 ms median and is
retained as a separate diagnostic. All outcomes and the method change are
preserved, rather than treating the VM failure as a pass.

These measurements do not establish native API overhead, actual author speed,
or universal latency bounds. Do not subtract them from author completion times.
